# 07 — Sécurité et limites

Un builder manipule ordreflow, données de mempool et décisions de valeur. Les clés, endpoints de relay et accès RPC doivent être isolés. La validation côté nœud d’exécution reste indispensable avant toute soumission.

Le README avertit du risque de pertes liées aux reorgs. La branche develop est active et peut être instable ; les releases taguées sont destinées à un usage plus stable.

Ce parcours est documentaire : aucune installation, compilation ni exécution de test n’a été faite. Consulter les suites du dépôt pour vérifier les comportements.
